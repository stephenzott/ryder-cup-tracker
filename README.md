# Ryder Cup Tracker

Live score tracker for the 2027 golf trip (Whistling Straits & Blackwolf Run), built as a small Firebase app:

- **Firebase Hosting** — serves plain HTML/CSS/JS, no build step.
- **Firestore** — shared live data (roster, teams, round results) so standings update for everyone in real time.
- **Firebase Anonymous Auth** — lets the app gate score entry and roster admin behind two separate codes, without a real login system.

Setup and deployment instructions will be added here as the app is built.
